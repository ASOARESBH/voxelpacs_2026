# Prompt interno — Refatorar

```
1. Confirmar o gatilho concreto (diagnostics/ que motivou: duplicação, arquivo grande, dependência circular, etc.).
2. Delimitar exatamente os arquivos em escopo usando architecture/dependencias.md.
3. Garantir que contrato externo (API, evento, schema) não muda — se mudar, tratar também como nova-funcionalidade.
4. Refatorar em passos pequenos, validando a cada passo.
5. Atualizar patterns/, modules/ e architecture/dependencias.md ao final.
```

Ver `workflows/refatoracao.md` para o fluxo completo.
