# Prompt interno — Criar/Atualizar Documentação

```
1. Identificar o arquivo certo (não criar um novo arquivo solto se já existe modules/, architecture/ ou indexes/ correspondente).
2. Escrever o resumo de forma que substitua a necessidade de reler o código-fonte na próxima tarefa.
3. Preferir tabelas e listas objetivas a prosa longa.
4. Marcar explicitamente o que ainda é suposição ([A confirmar]) versus o que foi verificado no código.
5. Se o arquivo atualizado ultrapassar ~300 linhas, considerar dividir em sub-arquivos com um índice no topo.
```
