## Cuidados especiais para tabelas clínicas/DICOM

- `bi_pacs_estudos.institution_name` é o valor exato da tag DICOM `InstitutionName (0008,0080)` vindo do Orthanc — é a fonte de verdade. Nomes cadastrados manualmente em `bi_tenant_unidades_dicom` podem divergir em caixa/acentuação; todo matching normaliza via `InstitutionResolverService::normalize()` (reaproveitado por `PacsRoutingService::resolveTenant()`, ver `modules/servidor-pacs.md`).
- `bi_pacs_estudos` é espelho de metadados do Orthanc (sincronização incremental automática via `PacsSyncService`, a cada 2 min, ou manual via botão `sincronizar()`) — não é fonte de verdade para os binários DICOM, só para metadados/roteamento.
- **Desde 2026-07-27**: o roteamento automático no momento da importação usa `PacsRoutingService`, que consulta `bi_tenant_unidades_dicom` (via o pivot `bi_negocio_servidor_pacs`) — cadastrar uma Unidade em Negócios agora roteia automaticamente os próximos ciclos de sincronização (não retroativamente para estudos já importados antes do cadastro, a menos que rodem de novo). `bi_pacs_roteamento`/`bi_negocio_institution_names` continuam existindo mas não são mais a fonte consultada por esse motor.
- `bi_pacs_estudos.modalities`: **Modality (0008,0060) é atributo de Series, não de Study.** `MainDicomTags` de `GET /studies/{id}` do Orthanc nunca contém essa informação — até 2026-07-11 o código lia `MainDicomTags.ModalitiesInStudy` (sempre `null`), por isso a coluna "M" do worklist sempre mostrou "—". Corrigido agregando `MainDicomTags.Modality` de cada Series via `GET /studies/{id}/series` (ver `modules/worklist-estudos.md` e `memory/regras-de-negocio.md`).

Ao mapear tabelas que armazenam dados DICOM (Study/Series/Instance) ou dados de paciente, documente explicitamente:

- Quais colunas correspondem a tags DICOM (ex: `StudyInstanceUID`, `AccessionNumber`) — mudanças aqui têm alto risco de quebrar interoperabilidade.
- Se há sincronização com o Orthanc (a tabela é espelho de metadados do Orthanc, ou é fonte de verdade própria?).
- Regras de retenção/privacidade aplicáveis, se conhecidas.
